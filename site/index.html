The Breadkit circuit checker

Check wiring before you build.

Analyze breadboard holes and component connections to find placement errors, shorts, floating pins, and mismatches with your design intent.

See a finding Browse rules

Install and run

gem install breadkit-lint
bklint circuit.bk.rb

What it checks

Placement

Invalid holes, part collisions, leads placed on the same strip, and ICs that miss the center gap.

Electrical connections

Shorts, unconnected pins, split rails, supply voltages, and LED series resistors.

Design intent

Differences between expect declarations and the resolved nets.

Use it locally or in CI

Choose text, JSON, GitHub annotations, or SARIF output. Set the severity that fails the run with --fail-level.

bklint circuit.bk.rb --format github
bklint circuit.bk.rb --format sarif --out lint.sarif
bklint circuit.bk.rb --only Electrical/ShortCircuit

Review findings on the diagram

Pass JSON results to breadkit-render to mark the reported holes and wires on the diagram.

bklint circuit.bk.rb --format json --out lint.json
bkrender circuit.bk.rb --annotations lint.json \
  -o review.svg
